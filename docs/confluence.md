# Вне афиши

«Вне афиши» собирает культурные события Башкортостана и помогает жителям и гостям региона подобрать события по дате, бюджету и аудитории. Сайт показывает каталог, чат подбора и пешие маршруты между выбранными площадками.

## Запуск

Скопируйте `.env.example` в `.env` и выполните `docker compose up --build -d`. Сайт работает на порту 8080, API на порту 8000. При первом запуске Compose скачивает модель Qwen2.5 7B. Данные PostgreSQL и веса модели сохраняются в томах Docker.

## Бот Telegram

Создайте бота в BotFather. Запишите токен в переменную `TELEGRAM_BOT_TOKEN` в корневом `.env`. Выполните `docker compose --profile telegram up --build -d`. Команда `docker compose logs -f bot` показывает состояние процесса. Бот принимает текстовый запрос и возвращает подборку со временем, площадкой, ценой и ссылкой на источник. Веб-вход использует почту. Для запуска бота имя бота и домен не требуются.

## Вход по почте

Задайте `SMTP_HOST`, `SMTP_FROM` и `EMAIL_CODE_SECRET`. Для сервера с авторизацией заполните `SMTP_USERNAME` и `SMTP_PASSWORD`. По умолчанию используется STARTTLS на 587, для SMTP поверх TLS задайте `SMTP_IMPLICIT_TLS=true` и при необходимости `SMTP_PORT`. Для публичного HTTPS-сайта задайте `AUTH_SECURE_COOKIE=true`.

Письмо содержит шестизначный код на 15 минут. После пяти неверных попыток требуется новый код. После входа сохраняется cookie HttpOnly на семь дней. Выход отзывает сессию в PostgreSQL. Запрос нового кода для одного адреса ограничен одним разом в минуту. Для одного адреса действует одна сессия.

## Данные и подборка

Импортёр «Бюро Культуры» работает при запуске и затем каждые 24 часа. Записи обновляются по внешнему ID. Площадка проверяется по границе Башкортостана. Карточки без подтверждённых координат скрываются. Семейный поиск использует пометки источника о детской или школьной аудитории. Ollama извлекает параметры и ранжирует карточки из PostgreSQL. Пешеходную геометрию рассчитывает FOSSGIS / OSRM, а подложку предоставляет OpenStreetMap.

## Тесты и доставка

Модульные тесты входят в сборку Docker. Интеграционный прогон: `docker compose -f compose.test.yaml -p afisha-test up --build --abort-on-container-exit --exit-code-from integration`. GitHub Actions проверяет Compose и публикует образы после успешного прогона на main. Автодеплой требует настроенного Linux-раннера. Подробности находятся в README.

## Предпочтения и совместный выбор

В профиле можно сохранить город, категорию, бюджет и фильтр детских событий. Чтобы получать подборку, привяжите бота через одноразовую ссылку и включите еженедельную подписку. Бот проверяет подписки каждые пять минут и отправляет до пяти событий в четверг после 18:00 по времени Башкортостана. Если подходящих событий нет, сообщение пропускается. Отвязка Telegram отключает подписку. Если имя бота отсутствует в настройках, API определяет его через Telegram getMe.

В чате есть редактируемые шаблоны запросов. Из двух–десяти выбранных событий можно создать голосование и поделиться ссылкой. Каждый браузер может оставить или поменять один голос. Лидеров можно перенести в маршрут. Для голосования с другого устройства используйте адрес развернутого сайта, доступный участникам.
